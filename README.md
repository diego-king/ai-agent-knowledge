`README.md` 和 `AGENTS.md` 只是仓库说明与编辑规范，不属于额外的学习资料。

- ChatGPT Mobile、Desktop、Web、Work 和 Codex 都以 `main` 的这三份文件为规范路径；**ChatGPT Project Sources 不会自动与 GitHub 双向同步**。
