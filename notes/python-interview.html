类型转换

age = 36
text = f"Age: {age}"
为什么不能直接 "Age: " + age？

字符串与整数不能直接使用 + 拼接，需要转换或使用 f-string。

List Comprehension

[x*x for x in range(6) if x % 2 == 0]
结果是什么？

[0, 4, 16]

并发选择

I/O-bound: threading / asyncio；CPU-bound: multiprocessing（视实现和版本而定）。

asyncio 是否让 CPU 计算自动并行？

不会。asyncio 主要用于合作式异步 I/O。
